# Разработка ядра бизнес-логики (Расчет скидки)

## Постановка задачи

Реализовать алгоритм функции, которая высчитывает индивидуальный процент
скидки партнёра на основе суммарного объёма купленной им продукции за весь
период.

### Критерии расчёта из ТЗ

| Суммарный объём, ед. | Скидка |
|----------------------|--------|
| < 10 000             | 0 %    |
| 10 000 – 49 999      | 5 %    |
| 50 000 – 299 999     | 10 %   |
| ≥ 300 000            | 15 %   |

### Требования

1. Изолированная функция (например,
   `calculate_partner_discount(total_quantity: int) -> int`).
2. Код строго по стандарту кодирования (`snake_case` для Python),
   одна команда в строке.
3. Unit-тесты на пограничные значения, покрытие 100 %.

## Состав работы

| Файл | Назначение |
|------|------------|
| `discount.py` | Изолированная чистая функция `calculate_partner_discount`. |
| `test_discount.py` | Параметризованные unit-тесты на границы диапазонов. |

## Реализация

Функция `calculate_partner_discount` не обращается к базе данных и не имеет
побочных эффектов. Подготовка входных данных выполняется на уровне слоя
интеграции с БД.

Логика построена на последовательных отсечениях:

- `< 10 000` → 0 %
- `< 50 000` → 5 %
- `< 300 000` → 10 %
- иначе → 15 %

Верхние границы диапазонов явно не проверяются, так как предыдущая ветка
отсекает все значения меньше нижней границы.

## Тестирование

`test_discount.py` использует `@pytest.mark.parametrize`. Проверяются:

- `0` — партнёр без истории продаж (`NULL` → `0`);
- `9 999`, `10 000`, `49 999`, `50 000`, `299 999`, `300 000` — границы
  диапазонов из ТЗ;
- `300 001` — проверка открытости верхнего диапазона.

Итого 8 кейсов. Покрытие функции — 100 %.

## Запуск

```bash
pip install -r requirements.txt

cd 01_business-logic
pytest -v test_discount.py
```

Ожидаемый результат — `8 passed`.
