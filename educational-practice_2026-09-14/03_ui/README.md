# Разработка интерфейса (UI) по руководству по стилю

## Постановка задачи

Пользователю (менеджеру компании) необходим визуальный интерфейс для
просмотра информации. Компоненты системы должны иметь единый согласованный
внешний вид.

Требования к UI из ТЗ:

- Заголовок окна/страницы должен четко соответствовать назначению (например:
  "CRM: Список партнеров и скидок").
- Установлена уникальная иконка приложения в углу окна (из папки ресурсов).
- На главной форме отображается логотип компании (из папки ресурсов).

Задача для студента:

1. Разработайте экранную форму (с использованием Tkinter/PyQt для Python,
   Windows Forms/WPF для C# или HTML/CSS для Web).
2. Разместите на форме элементы: шапку с логотипом компании, текстовый
   заголовок и главный макет (таблицу или список карт) для вывода партнеров.
3. Настройте элементы управления (шрифты, цвета фона и кнопок) в соответствии с
   "Screenshot_2".

## Состав работы

| Файл | Назначение |
|------|------------|
| `main_window.py` | Главное окно `MainWindow`: шапка, заголовок, список карточек. |
| `partner_card.py` | Виджет `PartnerCard` — карточка одного партнёра. |
| `style.qss` | Таблица стилей приложения. |
| `resources/logo.png` | Логотип компании в шапке (плейсхолдер). |
| `resources/icon.png` | Иконка приложения (плейсхолдер). |

Точка входа — `app.py` в корне этапа.

## Реализация

### Окно `MainWindow`

Заголовок окна: `CRM: Список партнёров и скидок`. Иконка приложения
устанавливается из `resources/icon.png`.

Структура окна:

- шапка с логотипом компании и текстовым заголовком;
- прокручиваемая область со списком карточек `PartnerCard`.

Данные карточек берутся из `repository.get_partners_with_discount()`.

### Карточка `PartnerCard`

Верхняя строка: тип и наименование партнёра слева, процент скидки справа.
Под верхней строкой — директор, телефон, рейтинг.

### Стилизация

QSS вынесен в отдельный файл `style.qss` и применяется через
`QApplication.setStyleSheet` в точке входа. Палитра — градации серого
в соответствии с «Screenshot_2».
