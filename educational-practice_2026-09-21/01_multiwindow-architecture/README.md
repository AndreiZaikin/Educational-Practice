# Проектирование многооконной архитектуры и навигации

## Постановка задачи

Приложение должно перестать быть одностраничным. Необходимо настроить систему
переключения экранов, которая позволит менеджеру перемещаться по приложению
без потери состояния и аварийных завершений.

Задача:

1. Создайте в проекте структуру для двух окон/страниц: `MainWindow` (Главная
   форма со списком партнеров) и `PartnerEditWindow` (Форма добавления/редактирования).
2. Реализуйте механизм последовательного перехода между ними:
   - На главной форме добавьте кнопку «Добавить партнера», которая открывает
     второе окно.
   - На форме редактирования добавьте кнопку «Назад» (или «Отмена»), которая
     закрывает текущее окно и возвращает пользователя на главную форму.
3. Обеспечьте для каждого окна индивидуальный уникальный заголовок (Window
   Title), строго отражающий его текущее назначение (например: "CRM: Реестр
   партнеров" и "CRM: Карточка партнера [Редактирование]").

## Реализация

`MainWindow` (`app/ui/main_window.py`) — главная форма со списком партнёров,
заголовок `CRM: Реестр партнёров`.

`PartnerEditWindow` (`app/ui/partner_edit_window.py`) — форма партнёра,
заголовок `CRM: Карточка партнёра [Добавление]` или
`CRM: Карточка партнёра [Редактирование]` в зависимости от режима.

Кнопка «Добавить партнёра» в шапке `MainWindow` открывает `PartnerEditWindow`
в режиме добавления. Кнопка «Отмена» в форме закрывает окно через `reject()`
и возвращает пользователя к списку.

Иконка приложения и логотип компании подключаются через `app/ui/paths.py`.
