# Интеграция формы с БД (CRUD-операции и обновление UI)

## Постановка задачи

Форма должна работать в двух режимах: создание новой записи и изменение
существующей с автоматической подгрузкой данных.

Задача:

1. **Режим добавления:** При нажатии кнопки «Добавить» на главной форме
   открывается пустая карточка. При сохранении данные уходят в БД, окно
   закрывается, а таблица на главной форме автоматически обновляется.
2. **Режим редактирования:** При двойном клике или нажатии на конкретного
   партнера в списке главной формы открывается карточка, в которую
   автоматически подгружаются и заполняются все актуальные данные этого
   партнера из БД. При сохранении выполняется запрос `UPDATE`.
3. Обеспечьте сохранение ссылочной целостности на уровне кода приложения.

## Реализация

### Функции слоя доступа к данным

В `app/db/repository.py`:

| Функция | Назначение |
|---------|------------|
| `get_partner_by_id(partner_id)` | Чтение одного партнёра для формы редактирования. |
| `get_partner_types()` | Справочник типов для выпадающего списка. |
| `create_partner(data)` | Вставка нового партнёра. |
| `update_partner(partner_id, data)` | Обновление существующего партнёра. |

### Режим добавления

Кнопка «Добавить партнёра» открывает `PartnerEditWindow` без `partner_id`.
Поля пустые. При сохранении вызывается `create_partner`.

### Режим редактирования

Двойной клик по карточке в списке эмитит сигнал `doubleClicked` с
`partner_id`. `MainWindow._on_card_double_clicked` открывает
`PartnerEditWindow(partner_id=...)`, форма подгружает данные через
`get_partner_by_id` и заполняет поля. При сохранении вызывается
`update_partner`.

### Обновление списка

После закрытия формы с результатом `Accepted` `MainWindow` вызывает
`_reload_cards`: контейнер карточек очищается, список партнёров
запрашивается заново через `get_partners_with_discount()` и
перестраивается.

### Ссылочная целостность

`partners.partner_type_id` — внешний ключ на `partner_types`. Значение
выбирается из справочника в `QComboBox`; при пустом выборе передаётся
`NULL`.
