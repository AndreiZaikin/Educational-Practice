# 03. Подготовка данных и импорт (ETL)

## Задание

- Очистите предоставленные файлы от аномалий (дубликаты, некорректные форматы).
- Выполните импорт подготовленных данных в вашу СУБД.
  - Разрешается использовать: команду `COPY` / `LOAD DATA INFILE` либо встроенные графические мастера импорта СУБД (DBeaver Data Import).
- Напишите проверочные запросы `SELECT COUNT(*)` по каждой таблице, чтобы убедиться, что все строки импортировались корректно.

Исходные файлы:

| Файл | Дата |
| :--- | :--- |
| `import_partners.csv` | 5 сентября 2026, 13:51 |
| `import_sales.txt` | 5 сентября 2026, 13:51 |

## Реализация

### Содержимое раздела

- `data/raw/` — исходные файлы, полученные в задании (не изменялись):
  - `import_partners.csv`
  - `import_sales.txt`
- `data/` — очищенные и нормализованные файлы, подготовленные для импорта:
  - `partners.csv`
  - `products.csv`
  - `deliveries.csv`
  - `delivery_items.csv`
- `import.sql` — скрипт импорта данных в PostgreSQL.

### Очистка данных

Исходные файлы содержали аномалии, которые были устранены при подготовке чистовых CSV:

- **Пустой `partner_id`** в строке 104 файла `import_sales.txt` → добавлен партнёр-заглушка `Unknown partner` (ID 4), ссылка на него проставлена в продаже.
- **Пустые `phone` и `rating`** у части партнёров → оставлены как `NULL` (колонки nullable).
- **Пустой `inn`** у партнёра-заглушки → оставлен как `NULL` (ограничение `UNIQUE` допускает несколько `NULL`).

### Нормализация структуры

Исходный `import_sales.txt` имел плоскую структуру: одна строка = одна позиция продажи. Данные разложены по схеме 3NF:

- `partners` — справочник партнёров.
- `products` — справочник уникальных товаров.
- `deliveries` — шапки отгрузок (накладные).
- `delivery_items` — позиции отгрузок.

### Импорт

Скрипт `import.sql` выполняет:

1. `TRUNCATE ... RESTART IDENTITY CASCADE` — очистка таблиц перед импортом.
2. `COPY` из CSV в порядке зависимостей:
   `partners` → `products` → `deliveries` → `delivery_items`.
3. `setval()` — синхронизация последовательностей PK после явной вставки ID из файлов.
4. Проверочные `SELECT COUNT(*)` по каждой таблице.
