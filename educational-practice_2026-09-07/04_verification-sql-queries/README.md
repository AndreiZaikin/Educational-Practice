# 04. Разработка проверочных SQL-запросов (Эмуляция бэкенда)

## Задание

Чтобы доказать, что база данных полностью покрывает бизнес-требования заказчика, напишите 3 SQL-запроса, которые будут использоваться будущим приложением.

Инструкция к заданию

Напишите скрипт `queries.sql`, содержащий:
1. **Запрос для вывода списка партнеров** с сортировкой по названию и выводом общего количества сделанных ими доставок (используйте `LEFT JOIN` и `COUNT`).
2. **Запрос для добавления/обновления данных** (демонстрация транзакции: создание нового партнера и запись о его первой тестовой доставке в рамках одного блока `BEGIN...COMMIT`).
3. **Запрос для истории реализации**: вывод детальной истории отгрузок конкретного партнера за указанный период (с названиями продуктов, датами, объемами в штуках и итоговой суммой поставки).

## Реализация

Основной файл — `queries.sql` — содержит все три запроса, как требует задание.

Дополнительно те же запросы вынесены в папку `split/` — по одному файлу на запрос. Это связано с двумя причинами:

- Query Tool (pgAdmin) при выполнении файла целиком показывает результат только **последнего** `SELECT`.
- Запрос с `INSERT` не идемпотентен: при повторном запуске падает на `UNIQUE (inn)`.

Разбиение на отдельные файлы позволяет запускать каждый запрос независимо и видеть его результат.

### Запрос 1. Список партнёров с количеством доставок

- `LEFT JOIN` — партнёры без доставок тоже попадают в список (для них `COUNT` вернёт `0`).
- `COUNT(d.delivery_id)` — считает только не-NULL.
- `GROUP BY` + `ORDER BY company_name`.

### Запрос 2. Транзакция: новый партнёр + доставка + позиция

- `BEGIN ... COMMIT` — атомарная запись связанных данных.
- ID передаются через `RETURNING` в CTE (`WITH ... INSERT ... RETURNING`), без `currval()`.
- Вставляются: партнёр, его доставка, позиция доставки.

### Запрос 3. История отгрузок партнёра за период

- Четыре `JOIN`: `partners → deliveries → delivery_items → products`.
- Захардкожены партнёр (`partner_id = 1`) и период (`2026-03-01` … `2026-03-31`).
- Вывод: дата, товар, количество, сумма позиции.
